# ✓ Launch checklist

Copy into the new game's first issue/PR. Every box must be ticked before the game is announced.

## Brand
- [ ] Name follows the Z-pattern (or a deliberate exception is noted)
- [ ] Wordmark: UPPERCASE, `font-light`, `tracking-[0.3em]`
- [ ] Tagline `Zero Distractions. Just <Game>.` on the start screen, `<title>`, OG, manifest
- [ ] `author` meta = `izzardry`
- [ ] Icon set: 192, 512, 512 maskable, favicon (all grayscale, all real PNG)
- [ ] OG image 1200 × 630 in the izzardry style; `og:image` is an absolute URL, `og:url` set
- [ ] Icon and OG image generated by a script from the game's own glyphs

## Look
- [ ] Ztyle tokens imported (`ztyle.css` + Tailwind preset); no ad-hoc colors
- [ ] Brand mono font bundled (works offline, same on all OSes)
- [ ] `halftone-bg` on the page root
- [ ] Only red/green used as color, and only semantically
- [ ] Light **and** dark checked; follows the system theme
- [ ] Identity shades (pieces, sides, QR codes) use the theme-stable inks and look the same in both themes
- [ ] Two-tone boards: light cells lighter in both themes; gray state fills at half the step (`foreground/5`)
- [ ] No glow or pulse is clipped by a neighbour or by `overflow: hidden`
- [ ] Buttons: one primary per screen, pills everywhere, icon buttons labeled

## Layout
- [ ] Board centered and stationary across start ⇄ game
- [ ] Start screen = blurred preview + Start pill
- [ ] All chrome floating, safe-area aware, hidden by tapping the background
- [ ] Portrait and mobile-landscape layouts both designed (rails in landscape)
- [ ] Board fits without scrolling from 320 × 568 up to 4K; one `--cell-size`, with a **measured** chrome reserve
- [ ] Screenshots checked at 320 × 568, 390 × 844, 844 × 390, 1280 × 800, 2560 × 1440, light and dark
- [ ] Toasts never cover the toolbar or the board
- [ ] Toolbar: one slot table for all modes; 44 px targets; ≤ 7 buttons

## Interaction
- [ ] Touch, mouse and keyboard can each complete a game
- [ ] Long-press durations follow the ladder (300 / 500 / 1000 / 3000 ms) and suppress the trailing click
- [ ] Every long press has a keyboard twin and is named in its `aria-label`
- [ ] Undo/redo for every move
- [ ] Destructive actions are immediate + undo toast (no confirm dialogs)
- [ ] `active:scale-95` on pressables; `select-none` on game surfaces

## Feedback
- [ ] Helpers toggle (on by default) bundles all spoiler-ish assistance
- [ ] Hints: tap = one step, hold = peek
- [ ] End state: page tint (success/destructive) + celebration overlay (🎉, title, summary, Share, New)
- [ ] Long work in workers; spinner in place; tooltip progress; tap to cancel
- [ ] End state against an opponent: tint from the device player's view, none for a draw

## Data
- [ ] Deterministic generation from an uppercase board code (6 generated, ≤ 8 typed), or the code as the game's name
- [ ] Full state in the URL (`s`, `d`, `p`, …); share = URL; cancelling the share sheet copies nothing
- [ ] Autosave every move; last 100 games; history with thumbnails, swipe/hover delete
- [ ] Storage keys `<game>:<key>`, all reads in try/catch

## Platform
- [ ] PWA manifest + service worker; network-first HTML (precache `directoryIndex: null`); offline playable
- [ ] Manifest icon paths relative (work under `base: "./"`)
- [ ] Large optional assets: not precached, downloaded with a status line, cache-first, re-checked each launch
- [ ] Install: once-only bottom sheet + persistent small pill
- [ ] Update toast with Reload; hourly check; never an automatic reload mid-game; version stamp (tap = copy + check)
- [ ] GitHub Pages deploy workflow; `base: "./"`; HashRouter
- [ ] Third-party binaries shipped unmodified with their licence and a credit line
- [ ] `lint`, `typecheck`, unit tests, build, and Playwright e2e against the production build all pass

## Rooms (only for a two-device mode)
- [ ] Code = room; Start creates or joins; invite link carries the code only
- [ ] Seat key with challenge-response; Allow toast for a device that lost its data
- [ ] Longest valid log wins; offline moves in untimed games; timed games pause
- [ ] Presence dot + one presence toast slot; reconnect with backoff
- [ ] Failure stated once with **Connect manually**; link/QR fallback works
- [ ] One tab per room (Web Locks)
- [ ] Played on two real phones on different networks

## Words
- [ ] EN, DE, FR, ES complete, including aria-labels (a missing key is a type error); `<html lang>` follows
- [ ] Difficulty ladder (12 levels) reused if applicable; default 5
- [ ] Copy reviewed against the voice table (short, calm, `!` only on success)

## Respect
- [ ] No ads, no tracking, no accounts
- [ ] Donation prompt once, after the first win, 1.5 s delay, "maybe another time"; the button drawn locally
- [ ] Support button at the bottom of the scroll area
- [ ] Tutorial overlay on first game; dismiss by tapping anywhere; reachable via `?`
- [ ] One small easter egg

## Accessibility
- [ ] Brand focus ring (no blue default)
- [ ] `prefers-reduced-motion` honored; one-shot marks have a still fallback
- [ ] Never color-only state
- [ ] Touch targets ≥ 44 px on coarse pointers
- [ ] Board: `grid` of labelled cells, roving tabindex; moves announced in a polite live region (turn-based games)
